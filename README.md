# 🏪 Sistema Loja + Vôlei

Sistema completo feito em Python para pequenos comércios de Itabaianinha-SE.

## O que faz
- ✅ Caixa do dia
- ✅ Controle de fiado (soma automático se o cliente já deve)
- ✅ Alerta de estoque
- ✅ Treino de vôlei por posição

## Como usar
1. Baixe o arquivo main.py
2. Rode no Pydroid 3
3. Escolha a opção no menu
